mke2fs.exe - ext2/ext3/ext4 for the USB Formatter on Windows
============================================================

mke2fs.exe is mke2fs from e2fsprogs 1.47.4 by Theodore Ts'o and others, unmodified, built for Windows
(lib/ext2fs/windows_io.c from e2fsprogs itself).

Licence: GNU General Public License version 2 (mke2fs), GNU Library General Public License version 2

Sources:
  e2fsprogs-1.47.4.tar.xz
  https://mirrors.edge.kernel.org/pub/linux/kernel/people/tytso/e2fsprogs/v1.47.4/
  SHA-256 fd5bf388cbdbe006a3d3b318d983b2948382440acc85a87f1e7d108653e8db0b

Build instructions for Windows (config.h, generated files, build script): folder windows/mke2fs/ of this project,
run: powershell -File windows\mke2fs\build_mke2fs.ps1

The formatter starts mke2fs.exe as a separate program and checks its SHA-256 checksum first.
