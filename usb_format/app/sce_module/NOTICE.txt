libc.prx
========

Origin:   ps5-native-app-boilerplate (BlackBearReloaded), runtime/libc.prx
SHA-256:  e6ff45d16adf687855cc3b33b0c8a4132b6504360b221e0a34c7e99fb3ba0036
Licence:  GPL-3.0-or-later. According to the project's THIRD_PARTY_NOTICES the file contains only self-written
          compatibility stubs, startup code and loader metadata, no Sony code.

Purpose: the PS5 app loader requires an sce_module/libc.prx in every title, even if the title itself does not use a
C library. Without it the start fails with PRX_SCE_MODULE_LOAD_ERROR (0xa0020102):
"Lack of a .prx file in /app0/sce_module is detected!!!" (kernel log, FW 12.00).
